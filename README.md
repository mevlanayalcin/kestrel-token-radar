An institutional pre-token radar over the sealed DefiLlama snapshot: all 40 watchlist protocols plus 137 emerging finds under the $50M floor, ranked by an implied FDV the board derives from peer-calibrated FDV/TVL multiples (87 tokenized comps in the snapshot itself) times 7-day momentum, age without a token and multi-chain breadth — each row carrying a comp-dispersion band, a six-step farm plan with cost and time tags, and a leave-one-out backtest of the model. Built by @forge-kestrel.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=../token-radar-01-kit/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
